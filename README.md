## Coursework

### 빅데이터를 이용한 통계 그래픽스 — R

#### Olympic Athlete Data Analysis
[프로젝트 보기](./빅데이터를이용한통계그래픽스)

올림픽 선수·경기 데이터를 활용해 R로 탐색적 데이터 분석과 시각화를 수행한 프로젝트

- 약 27만 건의 athlete-event 데이터 분석
- 결측치 처리 및 기초통계
- 성별·연령·키·몸무게 분포 분석
- 연도별 참가 추세 분석
- 종목별 선수 수·경기 수·메달 분포
- 국가별 하계·동계 올림픽 메달 패턴 비교
- BMI, 연령, 성별 등 선수 특성 시각화
